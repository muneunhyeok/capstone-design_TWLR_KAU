### 배터리와의 궁합
배터리는 **6S LiPo 22.2 V 5200 mAh** (만충 25.2 V). 24 V 형의 과전압 보호 32 V 까지
**6.8 V 여유**, 저전압 보호 15 V 는 6S 방전 하한(≈19.8 V)보다 낮아 정상 범위에서 꺼지지 않습니다.
회생제동 시 버스 전압이 순간적으로 올라갈 수 있으므로 감속 동작에서 전압을 모니터링할 것.

## 2. 고관절 필요토크 재계산

같은 CAD 질량 모델(벽 6줄 / 인필 20 %)에서 액추에이터 질량만 375 g 으로 바꿔 다시 돌렸습니다.

```bash
cd hardware/analysis
python3 mass_cog.py && python3 hip_torque3.py              # DM4340P (기본)
TWLR_ACT=AK45 python3 mass_cog.py && TWLR_ACT=AK45 python3 hip_torque3.py   # 이전안 재현
```

### 팀 권장 운용범위(3주차 발표)와 대조

3주차 발표의 권장 운용범위 Δφ = −21.6°(접힘) … +20.9°(펴짐) 를 이 저장소 부호로 바꾸면
Δθ = −20.9° … +21.6° 입니다.

| 끝점 | 필요토크 (CAD 질량 모델) | 정격 대비 | 피크 대비 |
|---|---|---|---|
| 펴짐 끝 Δθ = −20.9° (힙높이 528 mm) | 7.96 N·m | 88 % | 29 % |
| 접힘 끝 Δθ = +21.6° (힙높이 276 mm) | **14.50 N·m** | **161 %** | 54 % |

→ **운용범위 전체가 피크 27 N·m 안**에 들어옵니다 (AK45 였다면 접힘 끝이 피크 24 N·m 의 약 60 %).
접힘 끝에서는 정격의 1.6 배라 **오래 앉아 있는 자세는 피해야** 한다는 결론은 같습니다.

## 3. ⚠️ 팀 정역학(3주차)과 숫자가 다른 이유 — 확인 필요

| | 3주차 발표 정역학/동역학 | 이 저장소 (CAD 질량 모델) |
|---|---|---|
| 하중 | 토르소 **3 kg** (다리 1개당 14.7 N) + 링크 0.5 kg → 지면반력 19.6 N | 부품별 실측 체적·재질로 **BODY 4.62 kg** (배터리 0.7, 액추에이터 0.75 포함), 전체 11.24 kg |
| 최대 토크 | 접힘 끝에서 **8.5 N·m** (정적) / 동역학 T = 5 s 스쿼트도 ≈ 8.6 N·m | 접힘 끝 **14.5 N·m** |
| 판정 | 정격 9 N·m 의 95 % → 구동 가능 | 정격의 161 % → 단시간만 |

두 해석의 차이는 대부분 **토르소 질량 가정(3 kg vs 4.6 kg)** 과 링크 질량에서 옵니다.
토르소가 아크릴 + 3D 프린팅으로 재설계되었으므로(쇼케이스 영상의 모델), **실제 토르소 무게를 저울로 재서
한쪽으로 맞추는 것**이 다음 단계입니다. 토르소가 3 kg 이면 팀 결과, 4.6 kg 이면 이 표가 맞습니다.

## 4. 기구 변경 필요 사항 (CAD 미반영)

현재 Fusion 모델(`hardware/cad/TWLR_assembly_AK45.f3d`)의 고관절 인터페이스는 AK45 기준입니다.

| 항목 | AK45 기준 현재 설계 | DM4340P 로 바꿀 때 |
|---|---|---|
| 토르소 내부 격벽 관통 | Ø56 | 하우징 Ø57 → **Ø58 이상으로 확대** |
| `22_MNT_AK45_Ring` (하우징 고정) | 6 × M3, PCD48 | **Damiao 설치도면의 하우징 체결 패턴으로 재설계** |
| `21_HUB_Hip_Output` (출력 허브) | 6 × M3, PCD27 + Ø18 h7 스피곳 + 3 × Ø4 다웰 | **출력 플랜지 패턴/스피곳 치수 확인 후 재설계** |
| 볼트 마찰 전달 검토 (`bolt_check.py`) | 피크 24 N·m 기준 | 피크 **27 N·m** 로 재검토 (허브↔출력은 다웰 전제 유지) |
| 커넥터 / 배선 | XT30PW + UART | 전원 + **CAN (Teensy 4.1 ↔ CAN 트랜시버)** |

> 출력/하우징 체결 패턴은 판매 페이지에 수치가 없고 제조사 설치도면(다운로드)에만 있습니다.
> 도면 확보 후 `21_HUB`, `22_MNT` 두 부품만 바꾸면 되도록 허브/링 구조는 그대로 둡니다.

## 5. 제어 측면

- **절대위치 듀얼 엔코더** → 부팅 시 다리 각도를 바로 알 수 있어 원점 탐색 동작이 필요 없음
- **MIT 모드** (위치·속도·Kp·Kd·피드포워드 토크 동시 지령) → 다리 임피던스 제어와 중력 보상 토크를 한 프레임으로 전송
- 구성 계획 (BOM 기준): Teensy 4.1 + CAN 트랜시버로 좌·우 DM4340P 와 CAN 1 Mbps 통신, LattePanda 는 USB 시리얼로 Teensy 에 목표 자세·속도 전달 (3주차 발표의 상·하위 제어기 역할 분리)

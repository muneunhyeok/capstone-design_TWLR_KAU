## 2. 오른쪽 모터는 거울 장착 — 코드에서 부호로 통일

좌우 모터는 출력축이 서로 반대쪽을 보도록 대칭 장착 → 같은 + 명령에 L 은 접힘, R 은 펼침.
`DIR = { L: +1, R: −1 }` 을 **명령에도 피드백(각도 · 속도 · 토크 · ff)에도** 곱해 로봇 기준 + = 접힘으로 통일.
실물: 같은 명령에 양쪽이 같은 방향으로 접힘, `h` 유지 시 양쪽 +5 ~ 7° 처짐 · 토크 −2.8 ~ −3.4 N·m 로 부호가 같음.

## 3. 시험 방법 — 5° 계단 스윕

`hip_step_test`: `h` 로 현재 자세를 기준 0° → `g`(접힘) / `n`(펼침) 0 → 5 → … → 20 → … → 0°, 단계마다 1.5 s 유지, 100 Hz CSV 로그 → `plot_log.py`. 절차: [05](../../electronics/05-hip-drive-test-procedure.md)

## 4. 실측 토크 = Kp × 오차 — PD 만으로는 몸통을 못 든다

| | 계산 | 실측 |
|---|---|---|
| `h` 유지 · 처짐 6° | 30 × 0.105 rad = 3.1 N·m | 2.8 ~ 3.4 N·m |
| `n` 펼침 · 막힘 9° | 30 × 0.157 rad = 4.7 N·m | 4.5 ~ 5.1 N·m |
| 몸통 들기 필요 (해석) | 8.5 ~ 9.6 N·m → Kp 30 이면 오차 16 ~ 18° 필요 | 10° 자동 정지가 먼저 |

모터는 명령만큼 힘을 냈다. 부족한 건 명령 → 오차 대신 ff 로 토크를 채운다. 해석: [06](../../electronics/06-hip-torque-gravity-comp.md)

## 5. 원인을 고친 뒤 바퀴 접지 상태에서 접힘 · 펼침 성공

| 처음 못 폈던 이유 | 바꾼 것 |
|---|---|
| ① 펼 공간이 없었다 — 지그에 고정된 채 바퀴 접지 → −0.9° 에서 막힘 | 고정 해제, 사람은 앞뒤 기울어짐만 잡음 |
| ② 명령 토크가 작았다 — ff 없는 PD → 3 ~ 5 N·m 뿐 | 들기 모드 Kp 80 · Kd 3 + 중력보상 ff (뜨기 시작한 ff 값은 측정 중) |

전원 24 V 3 A 는 원인 아님 — 실측 토크가 Kp × 오차 계산값과 일치. 휠까지 돌릴 때는 전류 제한 상향 또는 6S 배터리.
